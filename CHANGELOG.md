# Changelog

## 1.0.0

First stable release under the TeXquill name.

- LaTeX and BibTeX completion, navigation, cross-file rename, signatures, and hover documentation.
- Formatting, semantic tokens, folding, linked editing, inlay hints, and structural refactoring.
- Push and pull diagnostics, build integration, bibliography processing, and SyncTeX coordinate queries.
- Neovim setup, a separately packaged VS Code extension, and feature documentation with editor demos.
- Precompiled GitHub downloads for Linux x64/ARM64, Apple Silicon macOS, and Windows x64; independent Cargo publication, a generated Homebrew Formula, and a pinned Nix flake.

Builds, external formatting, ChkTeX, and SyncTeX require separately installed tools. PDF viewer integration belongs to the editor client. See [installation](docs/install.md) and [migration from latex-lsp](docs/install.md#migrating-from-latex-lsp).
