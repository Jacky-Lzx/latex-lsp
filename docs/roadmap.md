2026-10-23 审阅：现有服务器已具备补全、参数提示、导航、项目隔离、跨文件重命名、语义令牌、折叠、颜色、编译及日志诊断、快速修复和 SyncTeX。以下按日常编辑收益、正确性和现有基础排序；实现后继续审阅，不将此列表视为完整功能定义。

1. **范围格式化**（已完成）：实现标准 `textDocument/rangeFormatting`。复用全文格式化上下文，仅返回完全位于请求范围内的编辑；覆盖 Unicode、CRLF、换行重排、取消及过期结果。270 项单元测试、6 项格式化协议回归、2 项真实 tex-fmt 回归及全目标 Clippy 通过。
2. **BibTeX 格式化**（已完成）：内置格式化完整普通条目的字段外空白，保留字段值、键、拼接、注释和条目顺序；支持全文及范围请求。7 项专项测试（含真实 BibTeX `.bbl` 一致性比较）、完整单元测试、格式化协议、55 项文献和语言回归及全目标 Clippy 通过。
3. **编辑时重复文献字段诊断**（已完成）：当前缓冲区中按字段名 ASCII 大小写不敏感检查，关联首次赋值，与精确编译器结果去重，支持增量清除及目录配置。8 项专项与 3 项相关协议测试通过；全量回归其余 2375 项通过，依赖初始化测试夹具修正后专项重测通过；全目标 Clippy 通过。
   - 后续协议复审（已完成）：范围格式化按 LSP 规则将超长列号收敛到行尾，继续拒绝代理对内部及不存在的行；复用严格／收敛两类坐标转换，覆盖语义令牌兼容性。完整回归 2378 项通过，全目标 Clippy 通过。
4. **数学定界符静态检查**（已完成）：可选 `diagnostics.mathDelimiters`，按行内／显示模式检查缺失、错配、嵌套及孤立关闭符号；排除定义参数头／正文、字面量、逐字代码和 token 操作数，对输入边界及共享文件保守处理。完整回归 2388 项通过；补充命名输入边界复审后，11 项专项（含真实 pdfLaTeX 对照）、推送／拉取协议及全目标 Clippy 通过。
5. **索引与术语表处理流程**（已完成）：`build.indexTools` 显式工具管线，复用后台任务生命周期；暂存输出、依赖校验、最多四轮收敛、命名索引并发冲突保护及 makeindex 拒绝条目校验。13 项专项（含真实工具）、3 项 stdio 状态／取消／保存保护测试通过；完整回归 249 组、2403 项通过（357 项默认跳过），全目标 Clippy 通过。

## 第二轮审阅

复查能力声明、编译调度、日志与快速修复之间的衔接后，下一轮按优先级安排如下。现有 selectionRange、linkedEditingRange、语义令牌 delta 和工作区拉取诊断已实现，不列为缺失项。

1. **匹配已配置索引任务的重编译操作**（待实现）：当前编辑器无条件隐藏全部索引请求的 `Rebuild …`。仅在警告文件、处理类型、产物目录和 jobName 与当前根的显式任务匹配时提供，执行时重新核对配置及诊断；保留未配置或不匹配时的提示。
2. **直接 TeX 引擎的文献处理流程**（待实现）：显式配置 BibTeX / Biber 阶段及后续 TeX 遍次，处理实际工作目录、数据库搜索路径、日志来源、取消和结果过期；当前完整流程主要由默认 latexmk 负责。
3. **索引工具诊断定位**（待实现）：把 `.ilg` 中的拒绝条目等消息呈现在编辑器诊断中，能确认来源时链接回原始条目；当前失败详情主要保留在编译输出。
4. **输入时格式化**（待实现）：标准 `textDocument/onTypeFormatting`，优先实现环境与分组的局部缩进，覆盖 UTF-16、CRLF、逐字代码和配置关闭，不在每次按键时运行外部全文格式化器。

每项实现应包含相应测试和使用文档，适时独立提交。全部完成后重新审阅协议、编辑体验、项目支持和构建工作流，补充下一轮清单。
