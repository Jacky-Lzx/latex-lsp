## 第二轮审阅

复查能力声明、编译调度、日志与快速修复之间的衔接后，下一轮按优先级安排如下。现有 selectionRange、linkedEditingRange、语义令牌 delta 和工作区拉取诊断已实现，不列为缺失项。

1. **匹配已配置索引任务的重编译操作**（已完成）：仅在警告文件、处理类型、产物目录和 jobName 与当前根的显式任务匹配时提供，执行时重新核对配置及诊断；保留未配置或不匹配时的提示。11 项操作测试、111 项日志解析测试、14 项相关日志回归、6 项 stdio 回归及 5 项索引请求测试（含三引擎真实回归）通过；全目标 Clippy 通过。
2. **直接 TeX 引擎的文献处理流程**（已完成）：`build.bibliographyTool` 显式配置 BibTeX / Biber，暂存辅助输入及文献产物、读取正式处理日志、再运行两遍 TeX；与索引共用四轮收敛、取消、依赖与过期校验，保留默认 latexmk 流程。完整回归 250 组、2421 项通过；随后完善辅助指令与生成数据库的收敛，11 项专项、2 项真实 BibTeX、4 项 stdio 及全目标 Clippy 通过。真实 Biber 回归需另行安装 Biber / biblatex 后运行。
3. **索引工具诊断定位**（已完成）：解析 makeindex 输入错误、样式错误与冲突警告，定位实际生成输入／样式文件的 UTF-16 行，无法确认时回退根文档；错误时保存本次日志并保留旧索引。宏展开后的条目暂不猜测映射到 `.tex`。5 项解析、15 项管线（含真实工具）、诊断发布／修复清除及 3 项相关 stdio、11 项文献管线回归和全目标 Clippy 通过。
4. **输入时格式化**（已完成）：标准 `textDocument/onTypeFormatting`，换行／输入 `}` 时按相邻行环境与分组调整行首空白；支持空格／制表符、UTF-16、CRLF、未保存缓冲区、全局／目录开关，排除逐字内容、注释与已知 token 操作数，避免宏定义内环境泄漏。8 项专项、全部 290 项单元、11 项格式化 stdio 回归及全目标 Clippy 通过。

每项实现应包含相应测试和使用文档，适时独立提交。全部完成后重新审阅协议、编辑体验、项目支持和构建工作流，补充下一轮清单。
