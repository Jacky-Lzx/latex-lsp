## 文献键与列表

文献悬停、引用补全和条目列表显示 BibTeX 条目的标题、作者与年份。预览折叠空白，并按字符限制长度；保留 TeX 源文字，不展开字符串宏、拼接表达式或继承字段，重复字段不作推断。

文献键支持普通圆括号，包括不配对括号，例如 `book(old)`、`book(old` 和 `book)old`。`\bibitem`、引用命令及两种条目定界形式的 BibTeX 数据库统一支持补全、跳转、语义标记和重命名；跨条目引用与元数据使用完整键，编辑保留注释及正文。

文献引用的键列表也支持跨行补全，包括普通 `cite`、natbib 和 biblatex 的已支持命令；只替换当前键，保留其他文献键、说明参数、换行和列表空白。

键名前后的 TeX 注释会保留，注释里的逗号和括号不参与键名解析。宏展开、嵌套分组和由注释拼接的非连续键名不作静态推断。

BibTeX 条目键后的逗号可以另起一行；支持 LF、CRLF 和缩进，导航与重命名保留键后的原始空白及元数据。

BibTeX 的 `@` 与条目类型之间也允许普通空白、换行和缩进，例如 `@ book{key, ...}`；特殊条目和字段内容仍按完整条目边界处理。

BibTeX 自定义条目类型支持数字后缀、下划线、连字符等合法标识符，例如 `@custom1` 和 `@custom_type`，参与索引、元数据和重命名。编译器关于未知样式类型的标准警告会定位到对应 `.bib` 条目的完整键；同键存在于多个数据库时保守保留原位置。

## 引用命令

普通 `cite`、`nocite`、natbib 及下述 biblatex 命令共用文献键索引。

natbib 的 `citealt` / `citealp`、`citenum`、`citeyearpar`、`citefullauthor` 及 `Citet` / `Citep` / `Citealt` / `Citealp` / `Citeauthor` 支持文献键补全、导航、引用、语义高亮、安全重命名、编译警告定位及拼写修复，并提供命令片段与参数提示。识别支持的星号形式及星号前后的空白和注释，保留引用列表、注释参数和正文。

biblatex 的 `fullcite` / `footfullcite` 与普通引用共用文献键导航、补全、引用查找、重命名及编译警告定位，并提供命令片段与参数提示。重命名保留前后注释、可选说明及引用列表中的其他键；这两个命令不支持的星号调用不会被当作文献键引用。

`bibentry` 宏包的 `\bibentry{key}` 正文内文献引用支持导航、悬停、引用查找、补全、参数提示、语义高亮和跨文件重命名；实际编译的缺失文献警告可定位到键名并提供拼写修复。按单个文献键处理，保留注释、条目正文和同名标签；不把键列表、动态名称或不支持的星号、可选说明当作可编辑键。

接受可选说明的普通引用命令最多识别两个说明参数；出现多余说明时，后面的正文不会参与文献键补全、导航、重命名或精确编译警告定位。说明参数按 TeX 规则在首个未受花括号保护的 `]` 处结束；文字中的 `[`、受花括号保护的方括号、空白和注释仍会保留，参数提示也遵循相同边界。

natbib 的 `defcitealias{键}{显示文字}` 使用单个静态文献键，`citetalias` / `citepalias` 引用相同的键。重命名同步维护别名设置与引用，保留键前后的注释及显示文字；逗号列表、含语义空白、宏或由注释拼接的动态键不作推断。别名设置本身不产生缺失文献键警告，不会领取同一行其他引用的编译诊断。

## biblatex 多组引用

支持以下标准命令及星号形式：

| 命令 | 首字母大写形式 |
| --- | --- |
| `cites` | `Cites` |
| `parencites` | `Parencites` |
| `footcites` | `Footcites` |
| `footcitetexts` | `Footcitetexts` |
| `smartcites` | `Smartcites` |
| `textcites` | `Textcites` |
| `autocites` | `Autocites` |
| `supercites` | 无 |

调用可先给出最多两个圆括号整体说明，再重复“最多两个方括号说明 + 花括号文献键列表”：

```tex
\parencites(整体前注)(整体后注)
  [参见][12]{alpha,beta}
  [34]{gamma}\relax
```

每一组的键都参与导航、引用查找、补全、语义高亮和重命名。从后续组或 `.bib` 条目发起改名会更新所有确认的引用，保留整体说明、各组说明及其他键。补全也支持后续组中尚未闭合的键列表；参数提示分别标明整体说明和各组的当前参数。

圆括号和方括号说明在首个未受花括号保护的右括号处结束，同类左括号不增加嵌套。组间允许空白和注释；空段落、普通正文或 `\relax` 会结束引用序列。多余说明、未闭合说明和动态键不会被猜测为静态文献键。卷号形式见下节。

编译器可能在向前读取下一条命令后才报告缺失文献警告。诊断会核对整个调用及其向前读取的位置，将警告定位到匹配键；多个匹配位置分别提供诊断和拼写修复。

## 卷号引用

以下 biblatex 命令区分卷号、页码和文献键，支持表中的大小写形式及星号：

| 单次引用 | 重复引用 |
| --- | --- |
| `volcite` / `Volcite` | `volcites` / `Volcites` |
| `pvolcite` / `Pvolcite` | `pvolcites` / `Pvolcites` |
| `fvolcite` / `Fvolcite` | `fvolcites` / `Fvolcites` |
| `ftvolcite` / `Ftvolcite` | `ftvolcites` / `Ftvolcites` |
| `svolcite` / `Svolcite` | `svolcites` / `Svolcites` |
| `tvolcite` / `Tvolcite` | `tvolcites` / `Tvolcites` |
| `avolcite` / `Avolcite` | `avolcites` / `Avolcites` |

每组按“可选前注、必选卷号、可选页码、必选文献键列表”读取：

```tex
\volcite[参见]{2}[12--16]{alpha}
\volcites(整体前注)(整体后注)
  [参见]{1}[12]{alpha,beta}
  [另见]{2}[34]{gamma}\relax
```

卷号、页码和前注即使与键同名，也不会被文献重命名或拼写修复修改。各组的键支持导航、悬停、引用查找、补全、高亮和跨文件重命名；缺失文献警告精确定位到键，允许编译器报告下一条命令的行号。

单次命令只读取一组；重复命令允许最多两个圆括号整体说明，后续组须以方括号前注或花括号卷号开始。也识别已开始组中的裸 ASCII 卷号或单个宏 token，例如 `\volcite2{alpha}` 和 `\volcites{1}{alpha}[另见]2{beta}`；不展开卷号宏。裸 Unicode、`^^` 转义及无法确认的 token 边界不作推断，文献键使用花括号分组。

补全片段只插入卷号和文献键两个必选参数，保留已有调用和可选说明。参数提示分别跟踪卷号、页码和各组键；填写说明或卷号后尚未输入必选参数时，继续提示下一个必选参数。普通多组引用也支持说明之后的等待提示。

## 手写文献

手写文献 `\bibitem[label]{key}` 提示可选显示标签与必选文献键。最多读取一个可选标签，在首个未受花括号保护的 `]` 处结束，保留其中的字面量 `[`；键后的正文、多余或未闭合标签及不支持的星号不会触发文献键编辑或提示。

声明识别键前后的注释，引用可导航到实际键名并参与重命名、语义高亮、重复定义检查和拼写修复。编辑保留可选文献标签和条目正文，跳过需要宏展开或含语义空白的声明。

## 条目关系与重命名

文献条目间引用支持 `crossref`、`xref`、`xdata`、`related` 和 `entryset`，包含花括号或双引号形式，以及后三类字段的逗号分隔列表；可补全、跳转、查找引用、高亮和重命名父条目。字段名不区分大小写，补全也支持尚未闭合的值。字符串宏、`#` 拼接或含 TeX 命令的值需要求值，暂不自动修改；标题和注释中的同名文本会保留。文献键不能重命名为 `*`，以免改变 `\nocite{*}` 的全选含义。

共享文献库的重命名覆盖使用它的各个主文档；其他项目中的同名条目保持独立。存在定义歧义、名称冲突或共享引用含义不一致时拒绝编辑。支持版本化工作区编辑；具体规则见[符号与重命名](symbols.md)。
