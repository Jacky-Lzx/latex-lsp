# PDF destinations and bookmarks

[Documentation](README.md) · [Editing features](editing.md) · [Tag and Cross-Reference](labels.md)

PDF internal targets and ordinary tags are indexed separately, and renaming only modifies the name in the selected namespace.

## Simple and combined goals

PDF internal anchors use independent namespaces: `\hypertarget`, `\hyperlink`, and static combination targets of `\hyperdef` / `\hyperref{}{category}{name}{text}` support navigation, referencing, highlighting, hovering, and safe renaming across files. `\hyperlink` provides complete target name completion, statement entry into the symbol list and repeat checking within the project. Tags with the same name remain independent; the combination target is matched according to `category.name`. When changing the name, the parameter separator, comment, line break, optional label and display text are retained. If necessary, the complete new name is placed into the name parameter after the empty category. Macros are not expanded, nor are anchors automatically generated by commands such as chapters inferred.

When the combined target retains the original category prefix, only the name field is modified. For example, after `section.start` is changed to `section.`, the declaration becomes `\hyperdef{section}{}{text}`. When changing to another prefix, the complete target is written into the name field after the empty category:

```tex
% section.start
\hyperdef{section}{start}{target text}
\hyperref{}{section}{start}{link text}

% rename to chapter.final
\hyperdef{}{chapter.final}{target text}
\hyperref{}{}{chapter.final}{link text}
```

## Bookmark level

The static target of `\pdfbookmark[level]{title}{name}` is indexed according to the actual `name.level`, the level defaults to `0`, and leading zeros and signs are retained; the above target editing functions, compilation diagnostics, spelling candidates, command snippets and signature help are supported. Rename using the complete target name, such as `chapter.intro.1`, update the name, level and link synchronously, fill in the optional level if necessary, and retain the title, comments and tags with the same name. The new name must have a legal numeric level suffix, and the level is a TeX integer no less than `-3`; commands such as dynamic levels, dynamic names, and `currentpdfbookmark` that depend on the current level are not inferred.

## Literal names and boundaries

PDF target names support ordinary parentheses, including unpaired parentheses; simple targets, classification targets, and bookmarks use the same literal rules to participate in jump, completion, citation, renaming, semantic markup, and accurate diagnostic spelling repair. Renaming preserves comment and bookmark level rules between category fields.

Square brackets in required curly brace parameters are also treated literally, allowing unpaired `[` or `]`; the optional label of `hyperdef` still follows [Protection Rules for Label Parameters](labels.md#hyperref-tag). The combined target can retain a non-empty category and an empty name, such as `section.`, but the full target name cannot be empty.

Regression testing continuously renames these targets, checking that links in the generated PDF still point to the new targets, and that labels with the same name, display text, comments, and parameter separators remain intact. For the operation method, see [Real Tool Regression](testing.md#rename).
