## 构建检查与测试

```sh
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

开发和测试构建默认关闭调试信息与增量缓存，以控制磁盘占用。需要源码级调试时，可按需设置 `CARGO_PROFILE_DEV_DEBUG=2` 或 `CARGO_PROFILE_TEST_DEBUG=2`；发布构建继续使用独立配置。

测试包含 UTF-16/增量编辑、语法容错、跨文件导航、文献补全、磁盘/未保存内容同步，以及启动真实进程验证的 stdio 协议流程。

`tests/language_ids.rs` 与 stdio 回归覆盖未命名文档、编辑器语言类型、项目输入角色的优先级，以及增量编辑、移动、关闭和重新打开时的解析器生命周期。

外部工具安装要求和各项测试命令见[真实工具回归](testing.md)。

## 解析范围

采用静态解析，不执行任意 TeX 宏展开，不读取 TeX 发行版的包数据库。不内置 PDF 预览、格式化或数学语义检查；重命名和修复遇到歧义时会拒绝编辑。

## 代码结构与分析缓存

`minted.rs` 共享 `mintinline` / `mint` 的头部及原始代码边界，分别读取普通选项、语言参数和 fvextra 的逐字参数。宏参数中的预分词上下文与 listings 共用 `InlineTokenization`，通过 `syntax::tokenized_code_end` 读取普通 token 和分组，普通源码仍使用 fvextra 的原始字符规则。语言与代码在语法主扫描中登记不透明范围，保留命令和可执行的头部选项；语义高亮、导航与重命名读取同一份范围。`inputminted` 的第三实参通过文件参数入口读取，使用面向 Python 字符串的无引号文件名包装，与 FancyVerb 通过 `code_inputs` 共享编辑分派、项目数据角色与构建快照。minted 的设置检查独立于 listings，复用 FancyVerb 的全局执行设置保护；原生和回退模式的缺失文件错误共用精确源码回显核对及版本化拼写修复。

minted 环境先以普通 TeX 规则读取选项和语言，再从下一行调用 FancyVerb 共享的正文结束扫描器；不能从整个头部起点简单搜索结束字符串。语法层继续将真实结束标记和结束行被丢弃的尾部分为两个不透明范围，使折叠及环境名联动编辑保留准确边界，尾部的示例命令不参与依赖和符号处理。

`listings.rs` 的环境结束扫描器先读取一次选项和名称 token，再确定正文起点。名称是活动换行时立即进入下一行；其他 token 或分组使扫描器丢弃该头部行的剩余内容。活动换行下的空白及注释跳过逻辑位于 `syntax.rs`，供 listings 与 FancyVerb 共用。只有正文中的精确关闭字符串结束 `lstlisting`，关闭后的行尾继续正常解析。原始不透明范围仍从环境名参数之后开始，使各编辑功能共享边界而无需重新扫描头部。

`lstinline` 在普通命令索引中保留调用，使用 `listings.rs` 读取普通选项及逐字代码边界；选项继续普通扫描，只有分隔符与代码登记不透明范围。星号作为分隔符读取，普通正文中的花括号形式终止于首个字面右花括号；缺少结束符时保留至行尾。宏参数的预分词判断复用 `CommandSignatures` 的已知参数语法和定义正文范围，查询分隔符之后的首个正文位置而非控制词或分隔符，避免把仅头部被消费的调用误认成预分词正文；预分词正文使用普通分组及 token 分隔符扫描，支持注释续行、嵌套分组和跨行。

词法上下文缓存已解析的参数语法并递增扫描前序调用，使用参数读取器返回的实际结束位置缓存预分词范围；普通外层作用域不会继承此状态。 行内命令别名先按新增声明增量记录候选转发边，仅在名称可达内置行内读取器时解析并确认当前含义；语法索引保留原始调用名称，代码与语言参数按实际读取器登记不透明范围。候选环、未知来源、参数化替换及歧义不会建立逐字含义。复制宏的稳定参数语法仅在行内词法上下文中解析，不改变导航对宏含义的判断；复制来源须无重复声明且已在复制前定义，纯静态转发保留晚绑定行为。 参数读取器另外返回未完成分组的读取进度，仅供词法上下文恢复；导航及编辑继续要求完整参数。原生 `def` 的参数头与完整定义分开读取，并按调用顺序排除作为宏参数消费的声明控制词，避免将普通分组误认成替换正文。语义高亮直接使用调用索引，只有原生 `verb` 需要从逐字范围前恢复宏 token。补全使用同一代码读取器判断是否已有正文，避免重复插入代码片段。

FancyVerb 的 `Verb` 直接调用与已证明的静态别名在同一词法分支读取头部，保留原始调用名称，并在普通符号及文件操作索引之前确定实际读取器。它共用预分词上下文和 token 分隔符扫描，但已收集正文中的控制词会执行；只将开闭分隔符登记为不透明范围，保留正文的普通扫描。直接源码及保存形式继续登记完整逐字范围，缺失关闭符时保留行尾恢复。头部与正文边界由 `fancyvrb::InlineHeader` 共享，重定义后不再应用内置正文及保存名称读取规则。`InlineContext` 按已索引的当前文件包加载区分 fvextra / minted 的逐字读取器，复用 minted 的正文边界；`fvset`、`fvinlineset` 与调用级 `extra` 按覆盖次序读取，设置随花括号、显式分组及静态直接环境调用保存和恢复，动态布尔值保守保留代码隔离。环境帧记录名称，结束时按现有环境诊断的恢复规则还原；意外的右花括号不弹出环境帧。逐字环境整体跳过，不压入需要其已跳过关闭命令来弹出的帧。 `VerbHeader` 按已收集参数或直接源字符区分头部空白读取，先证明正文位置的预分词状态，再选择实际头部；记录无可选参数时 fvextra 已预读的分隔 token，使原始 FancyVerb 读取器也保留该 token 的其他字符类别。`EscVerb` 与静态别名在普通索引前读取转义正文，头部共用星号和单个可选参数读取器，按预分词上下文及选项后的普通读取区分注释；正文复用普通平衡数据参数读取器，保留未闭合花括号诊断。补全复用头部及保存名称读取器判断已有参数；参数提示仅为拥有保存名称范围的命令穿过该数据范围，名称内注释和逐字正文继续拒绝提示。

环境头部提示复用 minted 的语言参数终点、FancyVerb 的头部终点、listings 的选项终点和通用签名参数读取器。只有实际逐字范围所属的直接 `begin` 能在一次头部查询中暂时穿过该范围，注释按 TeX 转义及换行规则单独核对；不修改语法索引或逐字范围。FancyVerb 的正文扫描与提示共享选项、必选 token 和活动换行边界，实际消费换行作为名称 token 时，提示范围停在该换行之前。listings 的提示只覆盖公开选项，名称 token 和被丢弃的行尾继续保持不透明。完整或未完成的头部均支持，正文查询继续走原有逐字拒绝路径。请求内检查当前项目的命令、环境声明、取消定义、FancyVerb 环境定制及 `lstnewenvironment`，避免重定义后错误使用内置参数列表。

`bib_diagnostics/biber_cycles.rs` 解析普通与 XDATA 的两个循环继承模板。日志循环只对明确且无歧义的当前模板，在记录致命级别之前复制有效输入集合；诊断查询消费这份局部来源，`Sources::record` 仍将当前错误及后续历史标为失效，不扩大可恢复错误的白名单。位置查询复用来源、文献键和关系字段缓存，普通循环可标记唯一 `crossref` 目标，XDATA 只使用条目键以兼容字段级循环；相关位置有界并去重。

`bib_diagnostics/biber_aliases.rs` 只解析三类完整的原生 IDS 冲突消息。来源按日志的完整此前输入选择，别名缓存沿声明顺序一次转换 UTF-16，保存规范化别名、共享所属键及每别名最多 16 个候选，同时单独计数以保留超限后的歧义。唯一被跳过别名还须核对所属真实主键的跨库唯一性；重复别名消息明确给出已接受的所属键，不能把它当成被跳过的键。主范围及相关范围共用静态索引，无来源文件名时不根据消息次序猜测声明。

`bib_aliases.rs` 按源码顺序联合遍历类型、字段、完整条目和主键，为唯一静态 `ids` 字段建立别名及其外层值索引；字段名使用原生读取器的 ASCII 大小写匹配。别名单独存储，只有编辑功能的文献声明迭代器合并它们，编译日志及数据库键缓存继续只读取真实条目头。独立别名重命名复用既有项目范围与冲突检查，双引号列表由保留的值范围合并为一次花括号编辑；语义声明及选择范围使用同一索引，不重新扫描文字。

`bib_completion.rs` 从文献解析器记录的条目类型、字段名和输入间隙生成补全、片段和悬停说明，保留已有字段值及注释；自定义类型沿用项目符号范围。类型索引还保存普通条目的键范围，使编译诊断能从键所在行定位到对应的类型名称。

`bib_symbols.rs` 使用类型索引的完整构造范围及字段的赋值范围建立文献大纲，保留键名和字段名的选择范围。字段按源码顺序一次遍历，归入对应条目；未完成正文也使用当前解析范围，折叠所需的完整构造索引保持独立。静态别名直接读取 `bibliography_aliases`，以键符号加入所属字段，沿源码顺序一次转换 UTF-16，避免单行长列表反复扫描前缀。平铺符号以直接父符号为容器，工作区搜索收集条目、别名与字符串符号，排除属性。

文献键使用独立的静态校验规则，允许字面双引号和括号；声明、普通与结构化引用、语义 token、编译警告定位和拼写修复共用该规则。向双引号关系字段插入含双引号的键时，补全转换整个值的定界符；重命名先合并值内各处替换，再生成一个花括号值编辑，避免重复列表键引起范围重叠。

选择范围复用文献键、标签参数和 BibTeX 关系值的边界。结构化引用由 `citations.rs` 的参数角色建立各参数及完整调用范围，命令结束位置取最后一个实参，避免吞入编译警告定位使用的前瞻 token。普通行范围与结构范围交叉时跳过该行候选，避免末行正文遮住跨行调用；输出前排除注释结尾的 CR，保证 LSP 坐标可读回源码。

`bib_strings.rs` 的表达式扫描同时记录选择范围：单个操作数、字面值内外层、完整表达式及赋值。未闭合字面值保留至当前输入末尾，包括其中的空白；有效缩写引用与编译修复可用声明仍遵循原有独立校验。编辑选择复用普通条目和特殊构造的完整解析范围，并把通用分组扫描限制在各个字面操作数内，避免不同值的方括号或注释内容形成交叉分组。

`bib_links.rs` 复用文献字段解析器建立 URL/DOI 链接索引，统一处理字面转义、URI 编码和重复字段。文档链接与语义高亮读取同一份索引，增量更新不保留旧字段的目标。

`bib_strings.rs` 识别 `@string` 和值表达式中的缩写，区分字面文本、数字、注释与 `#` 操作数；补全、符号及语义高亮共用该索引，导航和重命名复用项目范围与共享引用校验。真实 BibTeX 回归验证跨数据库表达式、preamble 及自引用的重命名保留输出。

BibTeX 语义高亮复用类型、字段及表达式索引，额外记录数字和运算符范围，不从选择范围推断 token 类型。原有六个 legend 索引保持稳定，末尾追加 `property`、`number` 和 `operator`。字面值背景的优先级低于文献键和精确链接；注释由条目边界扫描记录，保护引号键和字面值内的百分号，并以最高优先级覆盖候选。

条目类型、字段名和字符串缩写共享 BibTeX 标识符边界及首字符校验。合法的冒号、美元符号、反斜杠和非 ASCII 字节不会截断字段，也不会阻断其后字段的元数据、关系引用或字符串引用索引；数字开头的字段仍作为无效输入停止解析。

`bib_completion.rs` 从项目范围内已赋值的字段索引补充自定义候选，先读取当前文档以保留本地拼写；标准字段优先占用大小写不敏感的名称。当前条目的其他已赋值字段形成排除集合，编辑当前名称时仍可补全它本身。类型模板和字段模板共用名称的片段转义，已有赋值及普通文本客户端直接插入字面名称。

`bib_diagnostics.rs` 处理 BibTeX 的未定义缩写、未定义条目类型和重复条目诊断，共用有界来源解析缓存。缩写修复按日志读取顺序保存内容证明，只建议此前有效的数据库声明，复查内容证明、编译快照和版本；不会把月份编辑补全当成已加载的样式宏。重复条目复用文献键索引标出精确范围，按读取顺序关联此前的同名条目位置。Biber 记录头的级别解析由 `recorder.rs` 共享，诊断与数据库角色发现均核对实际级别，跳过正文中的伪记录。

普通样式警告和 Biber 条目消息也通过该缓存查找文献键。每份来源保存原始键到字节范围的映射，重复键使用显式歧义标记；查询时核对所有不同候选文件，拒绝跳过不可读输入后推断唯一性。已确认的键范围直接生成文献诊断，避免再进入通用 TeX 行诊断解析。显式文件名和独立行号的优先级不变，缓存不跨日志保留。

`bib_diagnostics/biber_keys.rs` 识别 Biber 数据库键之间的大小写消息和重复键警告，使用完整引号文件名和区分大小写的键索引定位主键。独立历史只记录此前实际读取的数据库，遇到语法或未知错误、缺失来源、截断或 1024 个输入上限后停止跨库关联；当前明确文件仍可定位。来源解析复用单文件 2 MiB、累计 16 MiB 的缓存，相关位置最多 16 个，不跨数据库猜测主键，也不推断两个键应当合并。重复键复用相同的来源和位置逻辑：相关键与主键相同，唯一主位置不重复列出，歧义位置全部作为有界候选保留；支持默认跳过重复项和保留重复项两种原生日志格式。

Biber 文献键位置按来源延迟建立缓存：沿源码中的声明顺序一次转换 UTF-16，保存首行回退范围和每个规范等价、区分大小写的键最多 16 个范围。Biber 专用 `key_name` 使用 NFD，与字段诊断共享，不改变普通 BibTeX 导航的原始键索引；规范等价声明共享候选上限。唯一主位置由候选表中仅有一个范围来确认，组合/分解形式发生碰撞时保留歧义；相关查询复用位置表，避免大量同一长行条目引起重复扫描。缓存属于当前日志的解析来源，文件及累计字节数沿用现有限制，每条消息继续检查当前来源历史的可信状态。

动态文献集合复用 `citations.rs` 的两参数边界，分别记录 `SetKey` 和 `Keys` 角色；成员引用沿用结构化引用索引。两个参数完整时，静态集合键加入 LaTeX 的文献声明索引，与手写文献、数据库键及别名共用已有导航、项目隔离和冲突检查。签名和成员补全读取同一参数角色，首参数不会作为成员引用或已有键补全。声明的语义 token、符号与选择范围复用文献声明，不另建动态集合命名空间。普通模式 Biber 测试夹具位于 `tests/support/biber.rs`。

`entrydata` 使用 `EntryData` 参数样式，分别记录单个 `Keys` 与 `Code(0)`，支持星号但不接受可选说明。`key_spans` 共用单键注释边界和静态校验，防止逗号列表被拆成引用；补全通过同一实参角色取得名称范围及注释外的空白删除范围，继续使用单行主编辑与附加编辑。参数提示、语义 token、选择范围和项目范围内的文献编辑读取既有索引，代码内的普通文字不会成为键。普通缺失引用诊断明确排除该命令，嵌套引用仍独立定位。

`ifentryexists` 和 `ifentryinbib` 使用 `EntryQuery`，复用单键与代码参数路径，`Code(index)` 区分两个分支。`context_codes` 同时驱动参数解析与签名；查询命令不接受星号，也不通过源码推断查询结果。两个分支继续按普通 LaTeX 解析，其中的字面文字不进入文献引用索引，静态嵌套引用仍独立参与编辑。

`bib_accessors.rs` 为三个数据引用命令的 `Selector` 参数与三个打印命令的最终必选参数提供名称补全和悬停。选择器目录区分普通字段、字面列表与姓名列表，只列出常用默认输出名称；说明复用 `bib_completion::field_description`。打印命令使用首个不受花括号保护的右方括号读取格式与范围，共用引用解析器的空白/段落边界。名称范围复用单键注释处理与单行补全编辑，`signature::uses_builtin` 核对实际签名，拒绝用户定义或含歧义的命令；不把选择器放入文献键索引，不展开数据模型。

不带格式的 `thefield` / `strfield` 与三个 undef 检查使用同一解析器的零可选参数路径，只读取首个名称分组。成立与不成立分支不参与名称补全；签名独立记录后续代码。内置签名检查同时调用 `generated::generated_command_exists`，排除当前符号范围内的计数器、定理和条件声明所生成的同名命令；不另建派生命令索引。

字段与列表比较复用零可选参数路径，`iffieldsequal` 读取两个连续字段分组，其他比较只读取首个名称。跨过首字段时使用平衡分组及段落边界，允许动态首字段后的静态第二字段编辑；比较字符串、命令操作数和执行分支不进入名称选择器。五个比较条件同样排除 `newif` 生成的覆盖。

`syntax.rs` 将三个 `equals` 命令的第二参数首个控制 token 记入 `control_operands`，兼容空前缀、未完成分组及注释。比较目标不触发命令自身的声明、文献引用或逐字语法。直接 `newif` 声明也登记词法赋值和名称操作数，避免继续套用同名内置条件的参数语法；不把它加入普通宏定义命名空间。

`ifentrytype` 复用零可选参数和单名称编辑路径，使用独立的条目类型候选与 `CLASS` 补全种类；描述由 `bib_completion::type_description` 与数据库类型悬停共用。目录只列常用默认输出类型，排除特殊条目、输入别名和 `xdata`，不从项目数据反推运行期条目类型。

`biber_nameparts.rs` 识别扩展姓名的未知组成部分警告，反向匹配固定字段与条目后缀，保留原生组成部分文本。所属键复用完整历史来源选择，字段值通过 `biber_model_field_ranges` 读取既有模型命名空间缓存；字段歧义回退到键，不重新解析已经展开的姓名字符串。该模块不列出固定的有效姓名部分，也不从日志值搜索原始词。

Biber 集合警告复用 `biber_fields.rs` 的历史来源选择与模型字段位置缓存，三种完整模板统一使用 `invalid-bibliography-set`。多余字段定位名称，缺失字段定位键；`reason` 区分两者。缺失报告不读取原始 ENTRYSET 字段范围，避免 source map 移除后误标源码中的现存字段。字段及来源歧义仍沿用已有回退，无需另建来源缓存。

`bib_diagnostics/biber_fields.rs` 解析 Biber 字段校验消息，区分字段名与字段值诊断代码。带明确数据库的消息反向匹配固定后缀，保留完整文件名；日期消息中的文件名与原始值可能包含相同边界，歧义时保留来源未确认的警告。文件解析复用 `biber_keys.rs` 的来源角色及搜索规则。默认年份、月份、ISBN 与畸形范围警告没有文件名，按固定后缀及最右条目分隔符识别；范围字段还校验原始字段标识符，月份只接受原生小写模板。随后遍历此前完整 Biber 输入历史；全部候选可读且键按 Biber Unicode 规范化后唯一时才定位字段，不采用当前库捷径。规范化键索引额外保留同库歧义集合，避免将碰撞误当作没有该键；读取超限或任何候选不可读时保留主文档诊断。

每份解析来源延迟建立字段位置缓存：规范化后的键先检查唯一性，再沿条目、完整构造与字段索引一次归属，按源码顺序转换 UTF-16。完整单一字面值使用内部范围，空值保留定界符，其他有效表达式使用整个右值。消息解析保存输入或模型拼写角色：未知字段、日期及畸形范围原生模板使用输入的 NFC → ASCII 小写 → NFD；已知字段的条目限制、数据模型校验及默认年份、月份和 ISBN 模板使用 NFD → 完整 Unicode 折叠 → NFD。两份字段表复用可复制的原始范围，只转换一次位置，避免回退 UTF-16 游标。各自保留显式歧义，模型折叠碰撞也不优先选择恰好同名的原始字段；完整正文、有效赋值及相应命名空间内唯一字段均满足时才定位。键继续使用区分大小写的 NFD，不改动其他 BibTeX 名称语义或源码内容。

`bib_diagnostics/biber_xdata.rs` 匹配三种完整 XDATA 缺失目标及类型错误模板，校验无符号 section 编号，保留原生消息和上下文。来源选择复用字段警告的完整此前历史与 NFD 键唯一性检查。字段范围缓存直接使用语法层按源码顺序产生的静态关系引用，在字段值起点与终点之间转换子范围，保持单次向前 UTF-16 扫描；重复目标的规范键存为歧义，重复或无效字段不能提供引用位置。动态、继承和映射字段只回退到所属键，不猜测其他原始字段。

`bib_diagnostics/biber_relations.rs` 识别缺失 `crossref`、`xref`、`related entry` 及 `static set member` 的完整消息，与 XDATA 共享严格的 section 后缀解析。关系范围缓存按字段分别存储规范化目标，因此相同目标出现在不同字段中不会互相覆盖；字段仍须有唯一有效的原始赋值。`Parsed::biber_reference_ranges` 同时返回所属键与可选精确引用，两个消息模块分别保留自己的诊断代码和原生上下文。缓存建立后也持续核对当前历史，错误或后续来源碰撞不能借用先前成功的位置。

`bib_diagnostics/biber_xdata_fields.rs` 解析四种完整的字段级 XDATA 消息，复用 section 校验和完整此前输入的来源选择。`Parsed::biber_input_field_ranges` 直接查询已有输入字段范围表，返回键和可选完整值，不重新扫描源码。真实 Biber 的 `add_xdata_ref` 接收输入字段名而不是完整折叠后的模型名，因此 `Straße` / `STRASSE` 等模型等价字段仍独立定位；输入规范等价碰撞则回退到键。源字段及父键只取原生模板明确给出的值，源位置以数字文本保留，避免将其误当作 LSP 位置或整数编辑依据。消息没有报告引用方列表项的位置，且 XDATA 标记可配置，因此整段标记原始赋值，不推断或修改某个值片段。

`bib_diagnostics/biber_names.rs` 反向匹配三种完整的姓名跳过模板，空姓名消息要求两处键完全相同，逗号模板允许姓名中包含另一模板的相似后缀。诊断使用 `malformed-bibliography-name`，保留原生级别和 `reason` / `name`，在此前所有可读输入中检查 NFD 键的唯一性，直接复用有界键范围表。原生姓名已可能经过 LaTeX 解码，自定义数据模型也可增加姓名字段，因此不定位或改写猜测的姓名片段。

Biber 输入历史仅对这三种确切模板保留可恢复状态：真实工具确认它们跳过单个条目后继续处理其他条目。`Sources::record` 使用同一纯解析器判断，不通过宽泛的 `Name` 前缀放行错误。其余 `ERROR` 消息，包括语法错误、未知错误、模板截断、键不合法及不匹配的空姓名键，仍使历史失效；之后即使新增输入也不恢复。本次解析的来源缓存、相关键查询及默认字段警告共用这项状态，避免一条已确认的姓名错误让后续全部诊断丢失位置。

字段模块另识别 `date` 覆盖 `year` / `month` 的完整固定模板，使用 `overwritten-bibliography-field`，不把有效但冲突的分量归类为无效值。主范围复用模型字段缓存及无文件名的历史检查，数据保存 `overwrittenBy: "date"`；同条目唯一、完整的原始日期值提供一个标准关联位置。原始分量缺失时回退到键，日期由 source map 生成或改名时不借用其他字段的相同值，也不借用父条目；两种范围查询均不重新遍历源码。诊断不提供删除或改写字段的修复。

`bib_diagnostics/biber_types.rs` 识别完整的 Biber 无效条目类型消息，使用独立 `invalid-bibliography-entry-type` 代码，避免触发 BibTeX 样式专用的类型修复。Biber 原生读取器对类型执行完整 `fc`，因此与模型字段共享 `biber_keys::model_name`，使用 ICU 2.3 `icu_casemap` 的默认完整折叠，前后规范分解；德语 ß 展开、希腊 sigma 及连字均按真实工具验证。依赖沿用已有 ICU 2.3 系列，锁文件只新增映射库和数据包，现有包版本保持不变。

类型名、折叠后的类型文本和字段范围在同一来源索引内缓存，按源码顺序先转换类型、再转换键和字段的 UTF-16 范围，不为每条消息重新扫描所有条目。只有完整条目中的唯一规范化键和相同折叠类型才允许定位类型名；真实 source map 改变类型时保留条目键及 `unresolvedType`，不把原本有效的类型标为无效，也不自动写回工具的 `misc` 默认值。

`bib_diagnostics/biber_required.rs` 识别 Biber 数据模型的单一必填字段和至少一项的备选组，以 `missing-bibliography-field` 标记明确数据库中的唯一条目键。完整后缀、字段标识符及备选组格式均核对原生模板，保留原始要求，不推导缺失值或插入编辑。定位复用 Biber 的 NFD 键缓存、规范化碰撞检查和来源角色，单字段及备选组分别输出 `field` / `fields` 数据；键歧义时使用来源首行，来源未确认或读取失败时保留主文档。

`bib_diagnostics/crossref.rs` 解析没有行号的两行原生 `crossref` 错误和嵌套警告，按记录类型严格匹配续行并保留不同的代码与级别。复用数据库缓存、完整条目范围、键索引及字段索引确定唯一字面操作数；缺失父条目的相关位置说明前置未引用条目可能被跳过，嵌套警告则链接报告中的父条目。数据库、键或字段有歧义时保留主文档诊断，不推测条目选择和修复。

`bib_diagnostics/fields.rs` 处理原生忽略重复字段的警告。字段索引保留值扫描的完整性结果，诊断以值后的定界符行匹配原生报告行，输出原字段名范围和首次赋值的相关位置。字段按条目顺序一次遍历；同一行的多个候选仅在警告组完整、数量一致且读取历史可靠时顺序配对。日志分组限制 16384 条记录和累计 16 MiB 名称数据，超限后保留可独立确认的单候选或行级诊断；来源读取复用现有有界缓存。

每组延迟缓存报告行范围、首次赋值和各个重复字段位置，与同一份解析来源绑定。匹配结果有歧义或数量不符时不保留候选列表，缓存范围数量由日志记录上限约束。字段位置按源码顺序一次转换 UTF-16，避免重复扫描长行；每条诊断仍独立核对当前读取历史是否完整，不能因为已缓存前一条警告而继续推断出错后的顺序。

同一次编译日志中的重复特殊字符、颜色、颜色模型、计数器、长度、toggle、boolean、环境及缺失输入文件、宏包、文档类错误会复用当前来源集合的宏签名和各类文档分析，减少大文档多错误时的重复解析。缓存只保留最近的宏来源集合及每类错误的一份文档分析；来源集合变化时重新分析，每条错误仍核对源码内容，不跨编译保留缓存。特殊字符修复的加载时序和来源校验见[宏来源说明](literal-macro-scopes.md)。

代码按职责拆分：`text.rs` 处理位置与编辑，`syntax.rs` 解析 LaTeX/BibTeX，`citations.rs` 共享多组、卷号及字段和列表引用的参数边界，`bib_resources.rs` 统一 biblatex 静态本地资源的选项、完整文件名与补全边界，`workspace.rs` 管理文件索引与根文档，`features.rs` 实现语言功能，`signature.rs` 提供命令参数提示，`navigation.rs` 处理工作区搜索和链接，`folding.rs` 处理语法折叠及客户端能力，`editing.rs` 处理快速修复、高亮和选择范围，`file_operations.rs` 维护文件移动后的引用，`graphics_settings.rs` 按源码顺序跟踪图片目录和扩展名的局部与全局设置，`build.rs` 管理后台编译，`build_log.rs` 分析日志，`recorder.rs` 读取实际输入记录，`synctex.rs` 查询源码/PDF 映射，`config.rs` 校验配置，`dispatch.rs` 保留消息顺序并释放耗时查询的等待，`lib.rs` 对接 LSP，`main.rs` 启动服务。
