# Missing right delimiters

[Back to documentation](README.md) · [Compilation diagnostics](diagnostics.md) · [Excess right delimiter](right-delimiters.md)

When the compiler reports `Missing \right. inserted.`, the server checks the recovery frame against the source code echo, locates the diagnostics to the marker that ends the math or explicit grouping, and provides a quick fix for `Insert invisible '\right.'`. For example:

```latex
$\left(a$                      % after the fix：$\left(a\right.$
\(\left(a\)                    % after the fix：\(\left(a\right.\)
\begin{equation}\left(a\end{equation}
% after the fix：\begin{equation}\left(a\right.\end{equation}
```

The inserted dot is TeX's invisible delimiter and is not displayed as a period. If visible right brackets are required, please use `\right)` or other writing methods according to the meaning of the formula.

## Support range

Supports `$` (including the first end character of `$$`), `\)`, `\]`, `\endgroup` directly pointed to by the log, and `math`, `displaymath`, `equation`’s `\end{...}`. The insertion position is before the closing tag, retaining the original tag, comments, blanks and newlines. Supports subfiles, UTF-16 ranges, CRLF, legacy and file line number logging; shortened source code echo must match uniquely on that line.

You must first read the accurate recovery frame `<inserted text>` / `\right .`, and then read the direct `l.N` source code echo. Additional user macro expansion frames, mismatched or ambiguous echoes, unknown sources, definition bodies, verbatim content, comments, and closing tags consumed by macros do not provide this operation. Corresponding fixes are also rejected when `right`, statically identifiable related end commands, or math environments are redefined within the project.

Some errors are delayed until `\end{document}`, such as some `\[...\]` recovery cases where amsmath is not loaded. The server retains these compilation diagnostics and does not use them to pad delimiters at the end of the document; nor does it infer insertion positions at the end of custom environments.

Insert one `\right.` in one operation. When multiple layers of matching are missing at the same position, the remaining errors will be processed after recompiling; some LuaTeX versions will repeatedly recover at the first error and then exit after reaching the error upper limit, so it may also need to be repaired in rounds. This operation does not eliminate other independent bracketing or grouping errors.

## Sources and old operations

The diagnostic code is `missing-right-delimiter`. The diagnostic marks the end tag and the actual edit is a zero-width insert at its starting point. `closingToken` in the diagnostic data saves the mark, `sourceContext` saves the source code echo, and `sourceLine` saves the echo line number starting from zero.

Quickly fix and reuse macro sources and parameter syntax confirmed at compile time; recheck source code, version, tags and dependencies when requesting operations and executing old client commands. After the parameter definitions in the source code, dependencies or `right` definition are changed, the old operations may become invalid and need to be recompiled. For source rules, see [Macro Source Description](literal-macro-scopes.md).

## verify

```sh
cargo test --locked --test right_delimiters
cargo test --locked --test right_delimiters real_missing_right -- --ignored
cargo test --locked --test protocol right_delimiter
```

True regression requires pdfLaTeX, XeLaTeX and LuaLaTeX. Repair sub-files step by step in 60 / 79 columns and two error formats, covering the above-mentioned closing tags, left delimiters generated by macros, cross-line comments and missing nesting. Finally, it is confirmed that one page of PDF is generated and the compilation errors are cleared. The stdio protocol regression covers both Code Action and legacy client commands, version checking, fake replacement rejection, and post-recompile diagnostic cleanup.
